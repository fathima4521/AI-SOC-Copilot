# 🛡️ AI SOC Copilot

An AI-powered Security Operations Center (SOC) Copilot built to assist with security analysis and investigation using **FastAPI, PostgreSQL, and Ollama**.

## 🚀 Features

* 🤖 AI-powered security analysis
* 🛡️ SOC investigation assistance
* ⚡ FastAPI backend
* 🗄️ PostgreSQL database integration
* 🧠 Local AI inference using Ollama
* 🔍 Security context and investigation tools
* 🌐 Web-based interface

## 🛠️ Tech Stack

* **Python**
* **FastAPI**
* **PostgreSQL**
* **Ollama**
* **HTML / CSS / JavaScript**
* **Git & GitHub**

## ▶️ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/fathima4521/AI-SOC-Copilot.git
cd AI-SOC-Copilot
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Start Ollama

Make sure Ollama is installed and the required model is available locally.

### 4. Start the FastAPI application

```bash
uvicorn main:app --reload
```

Then open:

```text
http://127.0.0.1:8000
```
